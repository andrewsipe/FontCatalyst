Flag reference

Canonical wording: fontcatalyst --help.

FlagMeaning
PATH…Font files or directories (required)
-r, --recursiveRecurse into directories
-o, --output-dir DIRWrite results to DIR and leave sources in place
-c, --consolidate [DIR]Per source folder: results in DIR (default _converted), originals in _archive; _quarantine only when a file fails
-ct, --consolidate-top [DIR]One result folder (default _converted_top), with _archive beside it
--repairApply the single fix the check named (coverage / PairPos, or a TTX rebuild)
convert -2, --toSubcommand. woff / woff2 lossless wrap, or otf (TTF outlines to CFF)
ttxSubcommand. Dump each font to .ttx. -r walks subdirectories. -c / -ct default to _ttx / _ttx_top
--versionPrint version and exit

Recipes

fontcatalyst fonts/ -r
fontcatalyst fonts/ -r -ct
fontcatalyst fonts/ -r -c
fontcatalyst fonts/ -r --repair
fontcatalyst convert -2 woff2 fonts/
fontcatalyst convert -2 otf Family.ttf
fontcatalyst ttx fonts/ -r
