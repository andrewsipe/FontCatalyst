Decompress, then look

fontcatalyst unwraps a WOFF or WOFF2 to the TTF or OTF stored inside it, then reports whether that file needs a repair this tool can do.

On this command, TTX is a repair. It runs only with --repair, and only when a table will not decompile. To dump a folder of fonts to XML, use fontcatalyst ttx. 
pipx install "git+https://github.com/andrewsipe/FontCatalyst.git"
fontcatalyst fonts/ -r -ct
