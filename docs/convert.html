Subcommand

Convert

One target per run, separate from decompress + review. -2 is --to. The result line states what happened to the outlines.

fontcatalyst convert -2 woff2 fonts/
fontcatalyst convert -2 woff fonts/
fontcatalyst convert -2 otf Family.ttf
-2 / --toResult
woffLossless zlib wrap. Outlines and hints stay. A variable font adds a note that WOFF2 is the usual container.
woff2Lossless Brotli wrap. Outlines and hints stay.
otfTrueType outlines refit as CFF. TrueType instructions are dropped.

WOFF and WOFF2

The container changes. The SFNT inside does not. A webfont is unwrapped first, then wrapped in the target flavor. If the file is already that flavor, Font Catalyst writes nothing and says so.

TTF to OTF

Fidelity warning. Quadratic outlines are refit as cubics (tolerance 0.001 em). TrueType instructions and related tables are dropped. This is not a cubic master. The warning is printed on every file.

Overlaps are removed when skia-pathops is available. CFF is subroutinized when cffsubr is available. An existing CFF font is left alone. Variable TTF to variable OTF is refused — decompress a variable webfont and keep the variable TTF. OTF to TTF is refused.

Folder flags

-c, -ct, and -o place that one target the same way as on the default command. A run does not emit a set of formats into labeled distribution folders.
