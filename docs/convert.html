Secondary command

Convert

Container wrap and the uncommon TTF to OTF path. Separate from decompress + review.

fontcatalyst convert --to woff2 fonts/
fontcatalyst convert --to woff fonts/
fontcatalyst convert --to otf Family.ttf

WOFF and WOFF2

Lossless wrap of the SFNT that is already there. Outlines and hints stay the same. Uses fontTools (zlib WOFF, Brotli WOFF2).

TTF to OTF

Fidelity warning. Quadratic outlines are refit as cubics (tolerance 0.001 em). TrueType instructions and related tables are dropped. This is not a cubic master.

Overlaps are removed when skia-pathops is available. CFF is subroutinized when cffsubr is available. OTF to TTF is refused. Variable TTF to variable OTF is refused — decompress a variable webfont and keep the variable TTF.

Same folder flags

-c, -ct, and -o work the same as on the default command.
